
Installation Requirements
=======

This mod runs on NeoForge 21.1.129. Install one of these loaders before adding SummonCraft to your game.

About
============

SummonCraft is a mod that adds a new summoning mechanic to the game.

Inspired by Terraria's summoner class, thia mod aims to expand upon Minecraft's existing stories to create its own take on what a summoner would look  like in Minecraft's world.
